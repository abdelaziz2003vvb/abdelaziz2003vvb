## 🔬 Recent Research

### 🧪 Automated 2D NMR Peak Detection

During my research internship at the **Institute of Molecular Chemistry of Reims (CNRS)**, I worked on:

> **Automation and Integration of NMR Data for the Identification of Compounds in Mixtures**

I developed an end-to-end AI framework for automated peak detection in **2D HSQC NMR spectra**.

**Key contributions:**

* 🧬 Synthetic HSQC spectrum generation with automatic ground truth
* 🧠 U-Net semantic segmentation for automated cross-peak detection
* 🔍 Classical peak detection: Harris, SUSAN, LoG, DoG, Hessian, Local Maxima
* 🌊 Watershed segmentation and DBSCAN clustering
* 📊 Evaluation using Dice, Precision, Recall and F1-score
* 🧪 Evaluation on synthetic and experimental HMDB spectra
* 🐍 Python-based scientific data processing
* 🔬 AI applied to scientific and chemical data

This project strengthened my interest in **AI for Science**, particularly the application of machine learning to complex scientific datasets.
